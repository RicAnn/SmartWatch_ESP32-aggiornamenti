# Smartwatch ESP32 – aggiornamenti

Gli aggiornamenti del firmware dello [Smartwatch ESP32](https://github.com/RicAnn) del prof. Riccardo Annolfi.

- `versione.json`: l'ultima versione (l'app "Orologio" la legge e avvisa se c'è un aggiornamento)
- `firmware/`: i firmware, **firmati**. L'orologio installa senza cavo solo quelli con la firma giusta.

Si installano dall'app: scheda AGGIORNAMENTO DELL'OROLOGIO, "Scarica e installa".

<sub>Realizzato con l'aiuto di Claude Code Opus 5.5.</sub>
